# 보스 방해 요소 + 장갑(의복) 시스템 — 설계 메모

> 상태: **브레인스토밍 중간 저장** (2026-09-30). 아직 설계 확정 전, 코드 반영 없음.
> 이어서 할 때: 이 메모 → `luck-enhance-design-review` 스킬로 표 초안 → 컨펌 → 구현.

## 배경 / 목표

- 토벌전·도서관 확장, 월드3를 계획 중이고, 여기서 **새로운 강화거리**를 찾고 싶음.
- 새로운 시스템도 추가하고 싶음.
- 관련 체크리스트 항목: `PATCH_CHECKLIST.md` → "상태이상 시스템 추가"
  (몬스터가 유저에게 거는 디버프, 토벌전 21~40단계 / 도서관 21~40서고 / 월드3 보스 등에 배치하는 방향).

## 핵심 컨셉

- **HP·방어력이 없는 현재 게임 구성은 그대로 유지.**
- 대신 **보스가 유저의 공격을 방해**하는 요소를 추가:
  - 유저에게 디버프를 걸거나,
  - 보스 자신이 공격을 방어하는 수단을 갖춤.

### 보스 방해 효과 예시 (사용자 제시)

| # | 이름 | 효과 |
|---|---|---|
| 1 | 회피 | 일정 확률로 공격을 회피한다 |
| 2 | 웅크리기 | 유저의 공격을 일정 %만큼 방어한다 |
| 3 | 암흑 | 유저의 명중률을 감소시킨다 |
| 4 | 예언 | 치명타 피해를 받지 않는다 |
| 5 | 스턴 | 일정 시간 동안 유저가 공격하지 못하게 한다 |
| 6 | 탈진 | 일정 시간 동안 유저의 공격속도를 감소시킨다 |

"등등, 다양한 효과가 있었으면 좋겠다" — 위 6개는 예시이고 더 늘릴 수 있음.

## 유저 측 대응 수단: "장갑" (의복)

- 위 디버프/방해를 **상쇄할 수단**이 유저에게 필요 → 여기서 **새로운 스탯 + 새로운 강화수단**이 등장.
- 컨셉: **장갑** (의복 장비).
- 공격력도 올려주지만, **메인은 상태이상 관련 스탯**.

## 아직 안 정한 것 (다음에 이어서 논의)

- 보스 방해 효과별 대응 스탯 매핑 (예: 회피 ↔ 명중, 스턴 ↔ 스턴 저항 …) 과 스탯 목록
- 장갑의 획득 경로 / 등급 / 강화 방식 (기존 무기·보조무기 강화와의 차별점)
- 어떤 콘텐츠(토벌전·도서관 확장 구간, 월드3)의 어떤 보스에 어떤 방해 효과를 배치할지
- 기존 무기 특수효과·고대 스피릿(유저→몬스터 효과)과 UI/용어가 헷갈리지 않게 하는 방법
- 수치 밸런스 (펀치기계 등 기존 측정 방식과의 연계)
