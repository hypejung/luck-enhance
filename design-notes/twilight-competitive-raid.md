# 황혼국 경쟁 레이드 (구상) — A안 「종언의 결투장」

> 상태: **1단계(결투장·순위 보상·칭호), 2단계(황혼 상점) 구현 완료(2026-10-17). 3단계 황혼의 악몽은 구현 전.** 아래 "2026-10-17 확정 사항" 참고. 사용자 결정: 협동이 아닌 경쟁(순위) 컨텐츠, A안.
> 관련: 세계수의 단말마(주간 협동 레이드) — 레이드 이름(`raidNames`)·TOP 3 세팅 보기·순위 칭호 구조를 그대로 재사용.

## 확정된 방향

| 항목 | 내용 |
|---|---|
| 보스 | 베스퍼리아, 황혼을 붙든 자 (40층 보스)가 레이드 보스로 재등장 |
| 방식 | 120초 동안 실제로 들어간 피해 측정(체력 사실상 무한, 펀치기계·세계수와 같은 측정 방식) |
| 차별점 | 보스가 **매주 바뀌는 방해 패턴 2~3개**를 씀(15종 중, 주차 키로 고정) → 주마다 장갑·보조무기·프리셋을 다시 짜는 "세팅 싸움" |
| 순위 기준 | 그 주 **1회 최고 기록**(세계수는 일일 최고 합산 — 여기는 한 방 승부) |
| 도전 횟수 | 하루 3회 |
| 해금 | 황혼국이 열려 있을 때 |
| 이름·세팅 | 레이드 이름은 세계수와 공유(`raidNames`), TOP 3 세팅 보기 |
| 조작 방지 | 넣지 않음 (사용자 결정 — "양심 문제") |

## 정할 것 (구현 때)

- 보상 구간: 1·2·3위 / 상위 10% / 30% / 50% / 참가. 재화는 황혼국 쪽(📜 무기의 정수, 🎫 토벌의 증표, 보조무기 강화 재료) — 세계수(푸른세계 재화)와 겹치지 않게.
- 1~3위 칭호(가칭): 🌆 황혼을 끝낸 자 / 🔔 종언의 종을 울린 자 / 🕯️ 저무는 빛을 지킨 자. 효과는 보조무기 쪽(결전의 기백 피해 등)으로 세계수 칭호와 다르게.
- 주간 패턴 조합 규칙: 토벌전 21~40단계 조합 재사용 vs 무작위(대응 스탯 안 겹치게, 도서관 금서의 저주 방식).
- 결산 시점: 세계수와 같은 일요일 0시인지, 다른 요일인지.
- 광폭화 여부(체력 무한이라 시간 기준 — 예: 90초 이후).

## 2026-10-17 확정 사항 (사용자 결정 + 추천안)

| 항목 | 내용 |
|---|---|

| 광폭화 | 90초 이후 패턴 효과 ×1.5 |

### 🛒 황혼 상점 (황혼의 정수, 가격 초안)
무기의 정수 20 / 토벌의 증표 50개 15 / 강철실 15 / 보조무기 강화 재료 20. **그림자는 팔지 않는다.**
→ 구현값(2026-10-17): 무기의 정수 20 / 각성의 정수 20 / 토벌의 증표 50개 15 / 강철실 15 / 강화 패널티 방지권 80. "보조무기 강화 재료"라는 단독 재료가 게임에 없어서 각성의 정수·방지권으로 바꿨다. 수량은 명예의 정수 상점과 같은 공식(`honorEssenceAmount` 등)을 쓴다. 코드: `TWILIGHT_SHOP`, `buyTwilightShop`.

### 🌑 황혼의 악몽 — 적응형 성장 장갑 (계정당 1개, 신화로 시작)
- **적응**: 결산 때(일요일 0시) 그 주 결투장 패턴 목록의 앞 **2개**의 대응 스탯을 각각 주·보조 스탯으로 삼고, 장갑 종류·이름·아이콘도 주 스탯에 맞는 종류로 바뀐다. 셋째 패턴은 대응하지 않는다. 결투 도전 중에는 바뀌지 않는다.
- **강화**: 확률·하락·파괴 규칙과 골드 비용 곡선은 같은 등급의 일반 장갑을 따른다(강철실 없음). 그림자는 시도마다 소모: +0~14는 0개, +15~19는 1개, +20 이상은 2개. 성장해도 강화 단계는 유지되고 곡선만 상위 등급이 된다.
- **성장**: 소모할 그림자 개수를 직접 고른다. 성공 확률 = (투입 / N)^1.5, N개에서 확정. 실패하면 투입한 그림자 전부 소멸(천장 없음). 신화→고대 N=60, 고대→태초 N=400.
- **등급별 효과**: 신화=없음 / 고대=스탯 9.2배 + 넘치는 대응 / 태초=스탯 11.5배 + 넘치는 대응 + 「악몽」 테마 패시브·반격 2개(구현 전에 표로 확인 후 ×2.5 측정).

| 투입 / N | 확률 | 고대(N=60) 기대 소모 | 태초(N=400) 기대 소모 |
|---|---|---|---|
| 25% | 12.5% | 120개 | 800개 |
| 50% | 35% | 85개 | 566개 |
| 75% | 65% | 69개 | 462개 |
| 100% | 100% | 60개 | 400개 |

기간 감각(그림자 합계 약 460 + 강화): 매주 1위여도 약 17주 이상, 상위 10%(주 8개)는 1년 넘게 걸린다. 1위도 쉽게 태초를 얻지 못하는 게 목표.

### 구현 순서
1. 결투장 + 순위 보상(정수·그림자) + 칭호 → 2. 황혼 상점 → 3. 황혼의 악몽(적응·강화·성장) → 태초 고유 효과 설계·측정.

### 1단계 구현 메모 (2026-10-17)
- 위치: 🌳 레이드 탭 안에서 `🌳 세계수의 단말마 / ⚔️ 종언의 결투장` 보기를 전환(`raidTabView`). 전투는 세계수와 같은 흐름(`bossFight.isWeeklyRaid` + `bossFight.isDuel`)이라 누적 피해 측정·시간 종료·중단이 그대로 동작한다. 코드는 `game-source.html`의 "종언의 결투장" 섹션(`DUEL`, `startDuelFight`, `endDuelFight`, `duelSettle`, `renderDuelTab`).
- 보스 체력은 `DUEL.refHp = 1e22`로 고정(처치하면 다시 채움). 세계수·펀치기계 더미(1e90)로 하면 보호막·분신·재생이 "최대 체력의 %"라서 의미가 없기 때문. **수치는 플레이 데이터를 보고 조정할 값**이다.
- 패턴: 주차 키로 고정, 대응 스탯이 서로 다른 3개(`duelPatternKeys`). 광폭화는 90초 이후 모든 패턴 ×`BOSS_ENRAGE_MULT`(1.5).
- 해금: 황혼국이 열려 있을 때(`S.unlocked > WORLD2_START_FLOOR`). 결산: 일요일 0시(주차 전환 시 `duelEnsureWeek` → `duelSettle`).
- 보상 구간은 순위/인원 비율로 정한다(상위 10%·30%·50%·참가). 1~3위는 칭호 + 위 표의 보상.
- 세이브: `S.duel`, `S.twilightEssence`, `S.twilightShadow`. 서버: `duelRecords/{주차}/{키}` = `{m, e, at}`, `duelSetup/{주차}/{키}` = `{s, at}`(Firebase 규칙은 사용자가 콘솔에서 추가). 이름·키는 세계수와 공유(`raidNames`, `weeklyRaidKey`).
- 테스트: `tools/test/duel.js`(도전 → 120초 틱 → 기록 업로드 → 결산).
