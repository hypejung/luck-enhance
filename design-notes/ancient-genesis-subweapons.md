# 고대·태초 보조무기 (월드2 21~40층) — 설계 메모

> 상태: **설계 진행 중** (2026-10-03). 코드 반영 없음.
> 순서: 고대 20종 효과 확정 → 이름·신화 레퍼런스 다듬기 → 구현·측정(×1.6) → 태초 20종(태초의 유물 설계 절차대로 5종씩).

## 확정된 공통 규칙

| 항목 | 고대 보조무기 (6등급) | 태초 보조무기 (7등급) |
|---|---|---|
| 구성 | 월드2 사냥터 21~40층마다 1종씩 20종 | 같은 방식으로 20종 |
| 종류 | 그 층 보스 보조무기와 같은 종류 (예: 21층 = 표창집) | 동일 |
| 효과 | 종류 패시브 + 결전의 기백(등급 배율 적용) + 고대 효과 1개 | 패시브 + 효과 2개 + 결전의 기백을 대신하는 고유 액티브 |
| 획득 | 그 층 몬스터 초저확률 드랍 1/1400만 (월드1 고대보다 1.3배 희박, 풀세팅 약 9일) | 1/6100만 (약 39일) |
| 강화 | 실패 시 파괴 대신 +0 초기화 (월드1 고대와 동일), 골드 + 무기의 정수 소모 | 파괴·초기화 없이 하락만, 무기의 정수 소모 |
| 강도 (+27) | 신화 +27 보조무기 대비 전체 화력 ×1.6 | ×2.5 |

- 기존 수집품 트랙 "고대 보조무기"(SUBWEAPON_RELICS, S.subRelics)는 이름만 **"🏺 황혼의 유산"**으로 바꾼다. 수집 현황·마일스톤 보너스는 그대로.
- 기준 강도: 신화 +27 보조무기 = 태초 +30 기준 120초 피해 ×3.36 (패시브·공격력 ×1.81, 결전의 기백 ×1.85).
- 보스 패턴 연동 효과(22·26·30·32·37)는 토벌전 21+·도서관 21+ 기준으로도 측정해 조정한다.
