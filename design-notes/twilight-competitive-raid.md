# 황혼국 경쟁 레이드 (구상) — A안 「종언의 결투장」

> 상태: **구상만 확정(2026-10-13), 구현은 나중에.** 사용자 결정: 협동이 아닌 경쟁(순위) 컨텐츠, A안.
> 관련: 세계수의 단말마(주간 협동 레이드) — 레이드 이름(`raidNames`)·TOP 3 세팅 보기·순위 칭호 구조를 그대로 재사용.

## 확정된 방향

| 항목 | 내용 |
|---|---|
| 보스 | 베스퍼리아, 황혼을 붙든 자 (40층 보스)가 레이드 보스로 재등장 |
| 방식 | 120초 동안 실제로 들어간 피해 측정(체력 사실상 무한, 펀치기계·세계수와 같은 측정 방식) |
| 차별점 | 보스가 **매주 바뀌는 방해 패턴 2~3개**를 씀(15종 중, 주차 키로 고정) → 주마다 장갑·보조무기·프리셋을 다시 짜는 "세팅 싸움" |
| 순위 기준 | 그 주 **1회 최고 기록**(세계수는 일일 최고 합산 — 여기는 한 방 승부) |
| 도전 횟수 | 하루 3회 |
| 해금 | 황혼국이 열려 있을 때 |
| 이름·세팅 | 레이드 이름은 세계수와 공유(`raidNames`), TOP 3 세팅 보기 |
| 조작 방지 | 넣지 않음 (사용자 결정 — "양심 문제") |

## 정할 것 (구현 때)

- 보상 구간: 1·2·3위 / 상위 10% / 30% / 50% / 참가. 재화는 황혼국 쪽(📜 무기의 정수, 🎫 토벌의 증표, 보조무기 강화 재료) — 세계수(푸른세계 재화)와 겹치지 않게.
- 1~3위 칭호(가칭): 🌆 황혼을 끝낸 자 / 🔔 종언의 종을 울린 자 / 🕯️ 저무는 빛을 지킨 자. 효과는 보조무기 쪽(결전의 기백 피해 등)으로 세계수 칭호와 다르게.
- 주간 패턴 조합 규칙: 토벌전 21~40단계 조합 재사용 vs 무작위(대응 스탯 안 겹치게, 도서관 금서의 저주 방식).
- 결산 시점: 세계수와 같은 일요일 0시인지, 다른 요일인지.
- 광폭화 여부(체력 무한이라 시간 기준 — 예: 90초 이후).
